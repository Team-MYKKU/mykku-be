[[preference-genre-update]]
=== 장르 취향 저장

로그인한 회원의 장르 취향을 요청한 `genreTypes` 목록으로 *전체 교체*합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고). 요청 본문을 인증보다 먼저 해석하므로, 본문 형식이 잘못된 요청은 토큰이 없어도 400 `C101` 이 먼저 반환됩니다.
* *전체 교체*: 성공하면 저장된 장르 취향이 `genreTypes` 와 같은 목록이 됩니다. 목록에 없는 기존 값은 삭제되므로, 추가·삭제한 항목만이 아니라 최종 선택된 전체 목록을 보내야 합니다.
* *현재 저장된 값은 다시 보낼 수 없음*: `genreTypes` 에 현재 저장되어 있는 값이 하나라도 있거나 같은 값이 두 번 들어 있으면 409 `C302` 가 반환되고 저장된 장르 취향은 바뀌지 않습니다(회원·값 조합 유일 제약). 저장된 장르 취향이 있는 상태에서 목록을 바꾸려면 빈 배열(`[]`)로 먼저 비운 뒤 최종 선택 목록을 보내세요.
* 빈 배열(`[]`)을 보내면 에러 없이 저장된 장르 취향이 모두 삭제됩니다.
* 굿즈·분위기 취향에는 영향을 주지 않습니다.
* 값은 대소문자를 구분하는 enum 이름(예: `KPOP`)입니다. 정의되지 않은 값이 있거나 `genreTypes` 가 없거나 `null` 이면 400 `C101` (<<overview-error-response,공통 에러>> 참고). <<error-code-api,에러 코드 목록>>에 있는 `PR101`, `PR102`, `PR103`, `PR104` 는 이 API에서 반환되지 않습니다.
* 응답 `data` 는 항상 빈 객체(`{}`)입니다. 저장 결과는 <<preference-genre-get,장르 취향 조회>> 로 확인합니다.

operation::preference/genre-update/200[snippets='http-request,request-headers,request-fields,http-response,response-fields']

[[preference-genre-get]]
=== 장르 취향 조회

로그인한 회원이 저장한 장르 취향을 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 저장된 장르 취향이 없으면 에러 없이 `data.genreTypes` 가 빈 배열(`[]`)인 200 응답을 반환합니다.
* 배열 순서는 보장되지 않습니다(저장 요청 순서나 enum 선언 순서와 다를 수 있습니다).
