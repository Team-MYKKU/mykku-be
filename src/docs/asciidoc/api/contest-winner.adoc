[[contest-winner-list]]
=== 수상작 목록 조회

수상자 발표가 끝난(`status` = `WINNER_SELECTED`) 콘테스트의 수상작 미리보기를 조회합니다.

* *인증 불필요*: 비회원도 호출할 수 있으며, `Authorization` 헤더를 보내도 무시됩니다.
* 수상자가 1명도 없는 콘테스트는 빠집니다. 해당하는 콘테스트가 없으면 `contests` 는 빈 배열입니다.
* 페이지네이션 없이 전체 목록을 한 번에 반환합니다.
* 콘테스트 정렬 순서는 보장되지 않습니다. 정렬이 필요하면 클라이언트에서 `expiredAt` 등으로 정렬합니다.
* 각 콘테스트의 `winners[]` 는 `winnerRank` 오름차순(1위 → 3위)이며 1~3개입니다. 수상 피드가 삭제되면 그 수상 기록도 함께 삭제되므로 순위가 비어 있을 수 있습니다(예: 1위와 3위만 존재).

* 콘테스트 상태를 확인하지 않습니다. 수상자가 아직 선정되지 않은 콘테스트(`status` 가 `WINNER_SELECTED` 가 아님)도 에러 없이 200 과 `winners: []` 를 반환합니다. 같은 상황에서 <<contest-winner-my-status,내 수상 여부 조회>>는 400 `WINNER_NOT_ANNOUNCED` 를 반환합니다. 발표 여부는 <<contest-detail,콘테스트 상세 조회>>의 `status` 가 `WINNER_SELECTED` 인지로 판단합니다.
* `winners[]` 는 `winnerRank` 오름차순(1위 → 3위)입니다.
* 콘테스트가 없으면 404 `CONTEST_NOT_FOUND` 를 반환합니다.

=== 수상자 발표 공지 조회

특정 콘테스트의 수상자 발표 공지글(제목/본문/발표일)을 조회합니다.

* *인증 불필요*: 비회원도 호출할 수 있으며, `Authorization` 헤더를 보내도 무시됩니다.
* 공지는 관리자가 수상자 선정과 별도로 등록합니다. 따라서 공지가 있어도 수상자가 아직 선정되지 않았을 수 있고(이 경우 <<contest-winner-my-status,내 수상 여부 조회>>는 400 `WINNER_NOT_ANNOUNCED`), 수상자가 선정되었어도 공지가 없을 수 있습니다. 공지 유무로 발표 여부를 판단하지 말고 <<contest-detail,콘테스트 상세 조회>>의 `status` 를 사용하세요.
* `announcedAt` 은 표시용 발표일입니다. 서버는 이 날짜 이전에도 공지를 반환합니다.
* 콘테스트가 없으면 404 `CONTEST_NOT_FOUND`, 콘테스트는 있지만 발표 공지가 아직 등록되지 않았으면 404 `WINNER_ANNOUNCEMENT_NOT_FOUND` 를 반환합니다. 두 경우는 응답의 `code` 로 구분합니다.

=== 내 수상 콘테스트 목록 조회

인증된 사용자가 수상한 콘테스트 목록을 페이지네이션으로 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 수상 기록 1건당 1항목입니다. 한 콘테스트에서 여러 피드로 수상했다면 같은 `contestId` 가 여러 번 나올 수 있습니다.

* 수상 이력이 없으면 `content` 는 빈 배열입니다.
* *페이징*: `page` 0 이상, `size` 1~1000. `page` 가 음수면 400 `C103`, `size` 가 범위를 벗어나면 400 `C104`, 숫자가 아니면 400 `C106` (<<overview-error-response,공통 에러>> 참고)
* 이 API 고유의 에러 응답은 없습니다 (인증·페이징 공통 에러만 발생).

[[contest-winner-update-acceptance-speech]]
=== 수상 소감 등록

수상자 본인(수상 피드로 콘테스트에 참여한 회원)이 수상 소감을 등록하거나 수정합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 여러 번 호출할 수 있으며, 호출할 때마다 기존 소감을 덮어씁니다. 콘테스트 상태나 기간 제한은 없습니다.
* `winnerId` 는 회원 ID가 아니라 수상 기록 ID입니다. <<contest-winner-my-status,내 수상 여부 조회>>의 `data.winnerId` 또는 <<contest-winner-detail,수상작 상세 조회>>의 `winners[].winnerId` 값을 사용합니다.
* `acceptanceSpeech` 가 비었거나 공백만 있거나 1000자를 넘으면 400 `C101` 이며, `message` 에 사유(`수상 소감은 필수입니다` 또는 `수상 소감은 1000자 이하여야 합니다`)가 담깁니다. 필드가 없거나 JSON 형식이 잘못된 경우도 400 `C101` 입니다 (공통 에러 참고). 빈 값으로 소감을 지울 수는 없습니다.
* 존재하지 않는 `winnerId` 면 404 `CONTEST_WINNER_NOT_FOUND`, 요청한 회원이 수상자 본인이 아니면 403 `NOT_WINNER_OWNER` 를 반환합니다.
