=== 내가 참여한 콘테스트 목록 조회

현재 로그인한 회원이 참여한 콘테스트 목록을 조회합니다. 각 항목에는 회원의 수상 결과(`winnerStatus`, `winnerRank`)가 포함됩니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* *참여 등록*: 별도의 참여 신청 API는 없습니다. 피드를 작성하는 시점에 `status` 가 `ACTIVE` 이고 `expiredAt` 이 지나지 않은 콘테스트가 있고, 피드 태그가 그 콘테스트의 `tags` 를 모두 포함하면 자동으로 참여로 기록됩니다.
** `startedAt` 은 참여 판정에 사용되지 않습니다.
** 태그가 없는 콘테스트에는 참여가 기록되지 않습니다.
** 피드 하나가 조건을 만족하는 여러 콘테스트에 동시에 참여로 기록될 수 있습니다.
* 피드를 수정해 태그를 바꿔도 참여 기록은 추가되거나 삭제되지 않습니다. 참여한 피드를 삭제하면 그 피드의 참여 기록과 수상 기록이 함께 삭제되어 목록에서 빠집니다.
* 참여는 피드 단위로 기록됩니다. 같은 콘테스트에 여러 피드로 참여하면 그 콘테스트가 참여 피드 수만큼 반복해서 나오며, `totalElements` 도 참여 기록 수 기준입니다. 항목에는 참여 피드 정보가 없고, 반복된 항목의 `winnerStatus`, `winnerRank` 는 콘테스트 단위로 계산되어 모두 같습니다.
* *정렬*: 참여 시각(참여 피드 작성 시각)의 최신순으로 고정됩니다. 정렬 파라미터는 없습니다.
* `status` 는 `expiredAt` 이 지나도 자동으로 바뀌지 않습니다. 마감 여부는 `expiredAt` 과 현재 시각으로 판단하세요.
* 관리자가 수상자를 선정하면 즉시 `status` 가 `WINNER_SELECTED` 가 되고 `winnerStatus` 가 `WON`/`LOST` 로 바뀝니다. 수상자 발표 공지글 게시 여부와는 무관합니다.
* *페이징*: `page` 0 이상, `size` 1~1000. `page` 가 음수면 400 `C103`, `size` 가 범위를 벗어나면 400 `C104`, 숫자가 아니면 400 `C106` (공통 에러 참고)
* 이 API 고유의 에러 응답은 없습니다 (인증·페이징 공통 에러만 발생).
