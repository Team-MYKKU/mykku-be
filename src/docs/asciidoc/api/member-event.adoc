[[member-events]]
=== 내가 참여한 이벤트 목록 조회

현재 로그인한 회원이 참여한 이벤트 목록을 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 마감 전(`ACTIVE`), 마감(`EXPIRED`), 당첨자 선정 완료(`WINNER_SELECTED`) 이벤트가 모두 포함됩니다. 아직 시작 전인 이벤트도 `ACTIVE` 로 내려옵니다.
* *정렬*: 회원의 참여 시각(참여 기록 생성 시각) 최신순으로 고정됩니다. 정렬 파라미터는 없습니다.
* 각 이벤트의 당첨 여부(`winnerStatus`)를 포함합니다. 관리자가 당첨자를 선정하면 즉시 `status` 가 `WINNER_SELECTED` 가 되고 `winnerStatus` 가 `WON`/`LOST` 로 바뀌며, 당첨자 발표 공지글 게시 여부와는 무관합니다. 관리자가 당첨자를 다시 선정하면 `WON`/`LOST` 가 바뀔 수 있습니다.
* *페이징*: `page` 0 이상, `size` 1~1000. `page` 가 음수면 400 `C103`, `size` 가 범위를 벗어나면 400 `C104`, 숫자가 아니면 400 `C106` (공통 에러 참고)
* 이 API 고유의 에러 응답은 없습니다 (인증·페이징 공통 에러만 발생).
