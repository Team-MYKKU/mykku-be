=== 공모전 목록 조회

공모전 목록을 페이지 단위로 조회합니다. 로그인이 필요하지만 응답은 회원과 관계없이 같습니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* `status` 필터 (기본값 `ACTIVE`): 저장된 ``status``가 아니라 ``expiredAt``과 요청 시점의 서버 시각(KST)을 비교해 거릅니다.
** `ACTIVE`, `WINNER_SELECTING`: 마감 전(`expiredAt` > 현재 시각)인 공모전. 아직 시작하지 않은 공모전(`startedAt` > 현재 시각)도 포함됩니다.
** `EXPIRED`, `WINNER_SELECTED`: 마감된(`expiredAt` ≤ 현재 시각) 공모전. ``expiredAt``과 같은 시각이 되는 순간부터 마감으로 분류되며, 수상자 선정 여부와 관계없이 포함됩니다.
** `ALL`: 전체 공모전
* 정렬 (``sortType``은 ``status``가 `ACTIVE` 또는 ``WINNER_SELECTING``일 때만 적용, 모두 등록일시 `createdAt` 기준)
** `LATEST` (기본값): 최신순
** `OLDEST`: 오래된순
** `POPULAR`: 현재 ``LATEST``와 같은 최신순
** `EXPIRED`, `WINNER_SELECTED`, ``ALL``은 ``sortType``과 관계없이 항상 최신순입니다.
* *쿼리 값 오류* (모두 400, <<overview-error-response,공통 에러>> 참고)
** ``status``·``sortType``에 정의되지 않은 값(대소문자 구분, 예: `active`)이나 숫자가 아닌 ``page``·``size``: `C106`
** ``page``가 0 미만: `C103`
** ``size``가 1 미만이거나 1000 초과: `C104`
* 응답의 ``status``는 저장된 상태값으로, 등록 시 ``ACTIVE``이고 수상자 선정이 끝나면 ``WINNER_SELECTED``입니다. ``expiredAt``이 지나도 자동으로 바뀌지 않으므로 마감 여부는 ``expiredAt``으로 판단하세요.
* ``winnerStatus``와 ``winnerRank``는 <<member-contests>>와 같은 응답 형식이라 포함된 필드로, 이 API에서는 항상 `PENDING` / `null` 입니다.

[[contest-detail]]
=== 공모전 상세 조회

공모전 하나의 상세 정보를 조회합니다. 로그인이 필요하지만 응답에는 회원별 정보가 없습니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 존재하지 않는 ``contestId``(0 이하 포함)는 `CONTEST_NOT_FOUND`(404), 숫자가 아닌 ``contestId``는 400 `C106` (<<overview-error-response,공통 에러>> 참고)
* ``images[]``는 `orderIndex` 오름차순으로 정렬되어 오며 썸네일(`thumbnailUrl`)은 포함하지 않습니다.
* ``status``는 <<contest-list,목록 조회>>와 같은 저장 상태값(`ACTIVE`, `WINNER_SELECTED`)이며 ``expiredAt``이 지나도 자동으로 바뀌지 않습니다. 마감 여부는 ``expiredAt``으로 판단하세요.
