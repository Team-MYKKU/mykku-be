[[event-list]]
=== 이벤트 목록 조회

이벤트 목록을 페이지 단위로 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* `status` 필터 (기본값 `ACTIVE`, 대문자만 허용)
** `ACTIVE`: 종료 일시(`expiredAt`)가 현재 시각보다 뒤인 이벤트. 시작 일시(`startedAt`) 전인 이벤트도 포함됩니다.
** `EXPIRED`: 종료 일시가 현재 시각과 같거나 지난 이벤트. 당첨자 발표가 끝난 이벤트(응답 ``status``가 `WINNER_SELECTED`)도 포함됩니다.
** `ALL`: 전체 이벤트
** `WINNER_SELECTING`, ``WINNER_SELECTED``를 보내면 ``ALL``과 같이 전체 이벤트를 반환합니다.
* 정렬 (``sortType``은 ``status=ACTIVE``일 때만 적용)
** `LATEST` (기본값): 등록일시 최신순
** `OLDEST`: 등록일시 오래된순
** `POPULAR`: 현재 ``LATEST``와 같은 등록일시 최신순
** ``EXPIRED``와 ``ALL``은 ``sortType``과 관계없이 항상 등록일시 최신순입니다.
* 응답의 ``status``는 조회 시점 기준으로 정해지며 `ACTIVE`, `EXPIRED`, `WINNER_SELECTED` 중 하나입니다. 당첨자 발표가 끝난 이벤트는 `WINNER_SELECTED`, 그 외에는 종료 일시와 현재 시각을 비교해 `ACTIVE` 또는 `EXPIRED` 입니다. `WINNER_SELECTING`, `ALL` 은 응답에 오지 않습니다.
* *페이징*: ``page``는 0 이상, ``size``는 1~1000. 범위를 벗어나면 400 `C103`(page) / `C104`(size), 숫자가 아니거나 ``status``·``sortType``에 정의되지 않은 값(소문자 포함)을 보내면 400 `C106` (<<overview-error-response,공통 에러>> 참고)

[[event-detail]]
=== 이벤트 상세 조회

특정 이벤트의 상세 정보와 로그인 사용자의 당첨 여부를 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* ``status``는 목록 조회와 같은 기준으로 조회 시점에 정해집니다. ``WINNER_SELECTED``가 되기 전에는 <<event-winner-my-status,내 당첨 여부 조회>>가 `WINNER_NOT_ANNOUNCED`(400) 에러를 반환합니다.
* ``isWinner``는 당첨자 발표 전에는 항상 ``false``입니다. 미당첨과 발표 전은 ``status``가 ``WINNER_SELECTED``인지로 구분합니다. 이벤트 참여 여부와는 관계없습니다.
* 존재하지 않는 ``eventId``(0 이하 포함)는 `EVENT_NOT_FOUND`(404), 숫자가 아닌 ``eventId``는 400 `C106` (<<overview-error-response,공통 에러>> 참고)
