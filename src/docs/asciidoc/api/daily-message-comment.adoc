[[daily-message-comment-list]]
=== 하루 덕담 댓글 목록 조회

하루 덕담의 댓글 목록을 페이지네이션으로 조회합니다.

* *인증 선택*: 로그인하지 않아도 조회할 수 있습니다. 로그인 상태라면 `Authorization` 헤더를 함께 보내야 좋아요 여부(`isLiked`)가 반영됩니다. 토큰이 없거나 유효하지 않으면(만료 포함) 401 없이 비로그인으로 처리되어 `isLiked` 가 모두 `false` 로 내려옵니다.
* *페이징 단위*: 최상위 댓글 기준입니다. `totalElements`, `totalPages`, `hasNext` 는 답글을 제외한 최상위 댓글로 계산되므로 답글까지 합친 총 댓글 수가 아닙니다. 답글은 각 댓글의 `replies` 에 페이지네이션 없이 모두 포함됩니다.
* *정렬*: 최상위 댓글은 작성 일시 최신순(`createdAt` 내림차순)으로 고정됩니다. `replies` 는 별도 정렬 없이 내려오므로 순서가 필요하면 클라이언트에서 `createdAt` 으로 정렬하세요.
* *작성자 정보*: 피드 댓글과 달리 `author` 객체 없이 `memberId`, `memberName`(닉네임), `profileImage`, `role`(대표 칭호)로 평탄화되어 내려오며, 피드 댓글의 `author` 에는 칭호가 없습니다. `memberName`, `profileImage` 는 작성 당시가 아닌 조회 시점의 회원 정보입니다.
* *탈퇴 회원*: 탈퇴한 회원의 댓글·답글도 목록에 남으며, 이때 `memberId`, `memberName`, `profileImage`, `role` 은 `null` 입니다. `profileImage` 가 `null` 이거나 빈 문자열이면 기본 이미지로 표시하세요.
* *프로필 미설정 작성자*: 아이디·닉네임을 설정하지 않은 회원이 작성한 과거 댓글은 `memberId`, `memberName` 이 `null` 일 수 있습니다(현재는 프로필을 설정해야 작성할 수 있음).
* *입력 오류*(모두 400, <<overview-error-response,공통 에러>> 참고): `page` 가 0 미만이면 `C103`, `size` 가 1~1000 범위 밖이면 `C104`, `dailyMessageId` / `page` / `size` 가 숫자가 아니면 `C106`. 마지막 페이지를 넘는 `page` 는 에러 없이 `comments` 가 빈 배열로 반환됩니다.
* 댓글·답글 좋아요는 <<like-daily-message-comment-create,하루 덕담 댓글 좋아요>> API를 사용합니다.

[[daily-message-comment-create]]
=== 하루 덕담 댓글 생성

하루 덕담에 댓글을 작성합니다. 같은 엔드포인트에 `parentCommentId` 를 함께 보내면 답글로 생성됩니다(<<daily-message-comment-reply-create,하루 덕담 답글 생성>> 참고).

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고). 요청 본문을 인증보다 먼저 해석하므로, 본문 형식이 잘못된 요청은 토큰이 없어도 400 `C101` 이 먼저 반환됩니다.
* *프로필 설정 필요*: 아이디와 닉네임을 모두 설정한 회원만 작성할 수 있습니다. 설정하지 않았으면 403 `MB201` 이므로 <<member-setup-profile,프로필 설정>> 화면으로 안내하세요.
* *내용*: 최대 1000자. 길이는 UTF-16 코드 유닛 기준(JavaScript `String.length` 와 동일, 이모지 1개는 2자 이상)입니다. 빈 문자열이나 공백만 있는 내용도 서버에서 거부하지 않습니다. `content` 를 빼거나 `null` 로 보내면 400 `C101` (공통 에러 참고)
* *칭호*: 댓글·답글 작성은 칭호 획득 활동(댓글 작성)으로 1회 집계되며, 피드 댓글·답글 작성과 합산됩니다. 누적 1 / 5 / 10회에 각각 '안녕하세요!' / '리액션천재' / '너 내 동료가 돼라' 칭호가 자동으로 부여됩니다. 칭호는 작성 처리(트랜잭션 커밋)가 끝난 뒤 비동기로 부여되므로 응답 직후에는 아직 반영되지 않았을 수 있습니다. 새로 받은 칭호는 <<role-new-roles,새로 획득한 칭호 조회>> 로 확인하세요. 댓글을 삭제해도 누적 횟수는 줄지 않습니다.
* 응답의 `likeCount` 는 항상 `0`, `isLiked` 는 항상 `false`, `replies` 는 항상 빈 배열입니다.

=== 하루 덕담 댓글 수정

본인이 작성한 하루 덕담 댓글 또는 답글의 내용을 수정합니다. 답글도 이 API로 수정합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고). 요청 본문을 인증보다 먼저 해석하므로, 본문 형식이 잘못된 요청은 토큰이 없어도 400 `C101` 이 먼저 반환됩니다.

[[daily-message-comment-delete]]
=== 하루 덕담 댓글 삭제

본인이 작성한 하루 덕담 댓글 또는 답글을 삭제합니다. 답글도 이 API로 삭제합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* 작성자 본인만 삭제할 수 있습니다. 다른 회원이 작성한 댓글·답글이면 403 `DM201` 이며, 작성자가 탈퇴한 댓글·답글은 누구도 삭제할 수 없습니다(403 `DM201`).
* *답글이 달린 댓글*: 답글은 부모 댓글과 함께 삭제되지 않습니다. 답글이 하나라도 남아 있는 최상위 댓글을 삭제하면 409 `C302` 가 반환되고 댓글은 그대로 남습니다. 답글은 각 답글 작성자만 삭제할 수 있으므로, 다른 회원의 답글이 달린 댓글은 그 답글이 삭제되기 전까지 삭제할 수 없습니다. 답글은 부모 댓글과 관계없이 삭제할 수 있습니다.
* 삭제한 댓글·답글의 좋아요도 함께 삭제됩니다.
* 응답의 `data` 는 항상 빈 객체(`{}`)입니다.
