[[board-feeds]]
=== 보드별 피드 목록 조회

특정 게시판의 피드 목록을 작성 일시 내림차순(최신순)으로 페이지 단위로 조회합니다. 정렬 방식은 고정이며 정렬 파라미터는 받지 않습니다.

* *인증 선택*: 로그인 없이도 호출할 수 있습니다. `Authorization` 헤더에 유효한 액세스 토큰을 보내면 로그인 회원 기준으로 응답이 계산되고, 헤더가 없거나 만료·유효하지 않은 토큰은 401 없이 비로그인으로 처리됩니다.
* *로그인 요청*: `isLiked` 가 요청자 기준으로 계산되고, 내가 차단했거나 나를 차단한 회원의 피드와 제목·본문에 내가 등록한 차단 키워드가 포함된 피드(대소문자 구분 없이 부분 일치)가 목록에서 제외됩니다.
* *비로그인 요청*: `isLiked` 는 항상 `false` 이며 차단 필터가 적용되지 않습니다.
* *차단 필터와 페이징*: 차단 필터는 페이지를 자른 뒤에 적용됩니다. 그래서 로그인 요청의 `feeds` 는 `size` 보다 적거나 0개일 수 있고, `totalElements` · `totalPages` · `hasNext` 는 필터 적용 전 기준입니다. 다음 페이지를 요청할지는 `feeds` 개수가 아니라 `hasNext` 로 판단하세요.
* *페이징*: `page` 는 0 이상, `size` 는 1~1000입니다. `page` 가 음수면 400 `C103`, `size` 가 범위를 벗어나면 400 `C104`, `boardId` · `page` · `size` 에 숫자가 아닌 값을 보내면 400 `C106` 이 반환됩니다 (<<overview-error-response,공통 에러>> 참고).

operation::board/feeds/200[snippets='http-request,request-headers,path-parameters,query-parameters,http-response,response-fields']

[[board-popular-feeds]]
=== 보드별 인기 피드 목록 조회

특정 게시판에서 요청 시점 기준 최근 7일(7×24시간) 안에 작성된 피드 중 좋아요 수가 많은 순으로 최대 3개를 조회합니다.

* *선정 기준*: 좋아요 수 내림차순이며, 좋아요 수가 같으면 최신 작성순입니다. 좋아요가 0개인 피드도 대상이므로 최근 7일 안에 작성된 피드가 있으면 좋아요가 없어도 목록에 포함될 수 있습니다.
* *인증 선택*: 로그인 없이도 호출할 수 있습니다. 헤더가 없거나 만료·유효하지 않은 토큰은 401 없이 비로그인으로 처리됩니다.
* *로그인 요청*: 상위 3개를 먼저 뽑은 뒤 내가 차단했거나 나를 차단한 회원의 피드와 제목·본문에 차단 키워드가 포함된 피드(대소문자 구분 없이 부분 일치)를 제외합니다. 따라서 3개보다 적게(0개 포함) 올 수 있고, 4위 이하 피드로 대신 채우지 않습니다. `rank` 는 제외 후 남은 피드에 1부터 연속으로 다시 매깁니다.
* *비로그인 요청*: 차단 필터가 적용되지 않습니다.
* `boardId` 에 숫자가 아닌 값을 보내면 400 `C106` 이 반환됩니다 (<<overview-error-response,공통 에러>> 참고).
