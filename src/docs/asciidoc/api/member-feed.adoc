[[member-feeds]]
=== 내가 쓴 피드 목록 조회

현재 로그인한 회원이 작성한 피드를 게시판 구분 없이 모두 조회합니다.

* *인증 필요*: 토큰이 없거나 유효하지 않으면(만료, 탈퇴 회원 포함) 401 `AU201` (<<overview-error-response,공통 에러>> 참고)
* *정렬*: 작성 일시 최신순(`createdAt` 내림차순)으로 고정됩니다. 정렬 파라미터는 없습니다.
* *페이징*: `page` 0 이상(0부터 시작), `size` 1~1000, 기본값은 `page=0`, `size=20` 입니다. `page` 가 음수면 400 `C103`, `size` 가 범위를 벗어나면 400 `C104`, 숫자가 아니면 400 `C106` (공통 에러 참고)
* `author` 는 항상 로그인한 본인이며 `null` 이 아닙니다. `isLiked` 는 본인이 해당 피드에 좋아요를 눌렀는지 여부입니다.
* *첫 댓글 미리보기*: `comment` 는 가장 먼저 작성된 최상위 댓글(대댓글 제외)이며, 댓글이 없어도 객체는 항상 포함됩니다. 댓글이 없거나 첫 댓글 작성자가 탈퇴한 경우 `content` 는 빈 문자열(`+""+`), `profileImage` 는 `null` 입니다. 첫 댓글 작성자가 탈퇴해도 다음 댓글로 대체되지 않으므로 `commentCount` 가 1 이상이어도 미리보기가 비어 있을 수 있습니다.
* 이 API 고유의 에러 응답은 없습니다 (인증·페이징 공통 에러만 발생).

[[member-feeds-empty]]
==== 빈 목록

작성한 피드가 없으면 `feeds` 가 빈 배열(`+[]+`)이고 `totalElements`, `totalPages` 는 0입니다. 마지막 페이지를 넘는 `page` 를 요청해도 `feeds` 는 빈 배열이며, 이때 `totalElements`, `totalPages` 는 실제 값입니다.
