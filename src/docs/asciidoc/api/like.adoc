피드·피드 댓글·하루 덕담 댓글의 좋아요와 게시판 즐겨찾기를 등록·취소하고, 즐겨찾기한 게시판 목록을 조회합니다.

* *인증 필요*: 모든 API는 로그인이 필요합니다. `Authorization` 헤더가 없거나, 토큰이 만료·변조되었거나, 탈퇴한 회원의 토큰이면 401 `AU201` 이 반환됩니다(<<overview-unauthorized>> 참고). 프로필 설정(아이디·닉네임)을 마치지 않은 회원도 호출할 수 있으며, 이때 등록 응답의 `data.memberId` 는 null입니다.
* 등록·취소는 멱등하지 않습니다. 이미 좋아요(즐겨찾기)한 대상에 다시 등록하면 400 `LK101`·`LK102`·`LK103`·`LK104`, 좋아요(즐겨찾기)하지 않은 대상을 취소하면 404 `LK001`·`LK002`·`LK003`·`LK004` 가 반환됩니다.
* 취소 API는 대상의 존재 여부를 확인하지 않고 본인의 좋아요(즐겨찾기) 기록만 확인합니다. 대상이 존재하지 않거나 삭제된 경우에도 `BO001`·`FD001`·`FD002`·`DM002` 가 아니라 404 `LK001`·`LK002`·`LK003`·`LK004` 가 반환됩니다.
* 등록·취소 응답에는 갱신된 좋아요 수나 좋아요 여부가 포함되지 않습니다. 화면의 좋아요 수·상태는 클라이언트에서 직접 갱신하거나 목록/상세 API로 다시 조회하세요.
* 등록 응답의 `data.id` 는 좋아요(즐겨찾기) 레코드 ID입니다. 취소 API는 이 값이 아니라 경로의 대상 ID(`boardId`, `feedId`, `feedCommentId`, `dailyMessageCommentId`)로 호출합니다.

[[like-board-list]]
=== 즐겨찾기한 게시판 목록 조회

로그인한 사용자가 즐겨찾기한 게시판 목록을 페이지 단위로 조회합니다.

* 정렬은 즐겨찾기한 시각의 최신순(`createdAt` 내림차순)으로 고정되며 변경할 수 없습니다.
* `page` 는 0부터 시작합니다. `page` 가 0 미만이면 400 `C103`, `size` 가 1 미만이거나 1000을 넘으면 400 `C104`, `page`/`size` 가 정수가 아니면 400 `C106` 이 반환됩니다(<<overview-pagination>>, <<overview-common-errors,공통 에러>> 참고).
* 아이템의 `id` 는 즐겨찾기 레코드 ID이며 게시판 ID가 아닙니다. 목록 아이템에는 게시판 ID가 포함되지 않습니다.
