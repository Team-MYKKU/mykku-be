[[overview-authentication]]
=== 인증

인증이 필요한 API는 `Authorization` 헤더에 JWT 액세스 토큰을 담아 요청합니다.

[source,http]
----
Authorization: Bearer {accessToken}
----

[[overview-response]]
=== 공통 응답 구조

모든 성공 응답은 다음 구조를 가집니다.

[source,json]
----
{
  "message": "응답 메시지",
  "data": { }
}
----

[[overview-error-response]]
=== 에러 응답 구조

모든 에러 응답은 다음 구조를 가집니다. 각 API의 **에러 응답** 항목에서 발생 가능한 에러를 확인할 수 있습니다.

[source,json]
----
{
  "code": "에러 코드",
  "message": "에러 메시지"
}
----

[[overview-http-status]]
=== HTTP 상태 코드

|===
|상태 코드|설명

|`200 OK`
|요청 성공

|`201 Created`
|리소스 생성 성공

|`204 No Content`
|요청 성공 (응답 본문 없음)

|`400 Bad Request`
|잘못된 요청

|`401 Unauthorized`
|인증 실패

|`403 Forbidden`
|권한 없음

|`404 Not Found`
|리소스를 찾을 수 없음

|`409 Conflict`
|리소스 충돌

|`429 Too Many Requests`
|요청 횟수 초과

|`500 Internal Server Error`
|서버 오류
|===
